# Глобал Дент — сайт стоматологии

Статический адаптивный сайт на HTML, CSS и JavaScript.

## Как открыть
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в браузере.
3. Для локального просмотра можно использовать расширение Live Server в Visual Studio Code.

## Файлы
- `index.html` — структура сайта, тексты, услуги, цены и контакты.
- `styles.css` — оформление, адаптивность и мобильное меню.
- `script.js` — мобильная навигация и автоматический год в подвале.
- `assets/logo.png` — логотип, предоставленный заказчиком.

## Что уже работает
- Навигация по разделам сайта.
- Ссылки для звонка и WhatsApp.
- Ссылка на карточку клиники в Яндекс Картах.
- Адаптивная версия для смартфонов и планшетов.
- Все 9 услуг и указанные цены.

## Перед публикацией проверьте
- Актуальность прайса и то, что входит в каждую услугу.
- Фото в разделе «О клинике» заменено на предоставленное заказчиком. В главном экране пока используется демонстрационное изображение с Unsplash; при желании замените его на реальное фото клиники.
- Подтверждение адреса, телефона, режима работы и карточки на Яндекс Картах.
- При необходимости добавьте юридические сведения клиники, лицензионные данные, политику обработки персональных данных и форму записи.

## Важно
Сейчас запись ведёт в WhatsApp. На сайте нет базы данных, личного кабинета или отправки заявок на сервер. Внешние изображения и Google Fonts требуют подключения к интернету.
